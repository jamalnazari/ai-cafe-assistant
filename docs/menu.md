# دادهٔ منو و پیشنهادهای هوشمند

## ساختار داده

- **دسته‌بندی:** `menu_categories` با `name` یکتا در هر رستوران و `sort_order` برای ترتیب نمایش.
- **آیتم:** `menu_items` با `item_key` پایدار و یکتا در هر رستوران (ایندکس یکتا)،
  `sort_order` برای ترتیب داخل دسته، `aliases` برای نام‌های جایگزین و
  `image_filename` برای تصویر.
- **قیمت:** در دیتابیس به **ریال** (`price_amount`) ذخیره می‌شود؛ API همان مقدار را
  برمی‌گرداند و رابط کاربری آن را به **تومان** تقسیم بر ۱۰ نشان می‌دهد.
- **آلرژن:** `null` یعنی «بررسی نشده» و `[]` یعنی «بررسی شده و آلرژنی ثبت نشده است».
- **دما:** یکی از `hot`، `cold` یا `room_temperature`.
- **تصویر:** فایل در `uploads/menu_items/` سرو می‌شود و آدرس آن در
  `image_url` با مسیر `/api/v1/uploads/menu-items/<file>` برمی‌گردد.

## دادهٔ نمونه و تصاویر

تصاویر منبع در `apps/api/app/data/menu_images/` نگهداری می‌شوند و اسکریپت seed
آن‌ها را به پوشهٔ runtime کپی می‌کند. برای ساخت/به‌روزرسانی منوی نمونه:

```powershell
cd apps/api
.\.venv\Scripts\python.exe -m app.db.seed_demo_menu
```

این اسکریپت idempotent است: ستون‌های جدید را با `init_db` می‌سازد، کلیدهای قدیمی
را به slug استاندارد تبدیل می‌کند، ۲۴ آیتم در ۵ دسته‌بندی (غذای ایرانی، فست‌فود،
نوشیدنی سرد، نوشیدنی گرم، دسر) را می‌سازد و دسته‌های خالی/آزمایشی را حذف می‌کند.
منبع و مجوز تصاویر در `apps/api/app/data/menu_images/ATTRIBUTION.md` آمده است.

## قرارداد دستیار

`POST /api/v1/restaurants/{slug}/ask-text` خروجی زیر را برمی‌گرداند:

```json
{
  "answer": "متن پاسخ فارسی",
  "recommended_items": [
    {
      "id": "latte",
      "name": "لاته",
      "category": "نوشیدنی گرم",
      "image_url": "/api/v1/uploads/menu-items/latte.jpg",
      "price": { "amount": 1450000, "currency": "IRR" },
      "is_available": true
    }
  ]
}
```

پرامپت LLM از یک سند **JSON ساخت‌یافته** شامل شناسه، نام دقیق، دسته، قیمت تومانی،
ترکیبات، آلرژن، تندی، دما، وضعیت موجودی و نام‌های جایگزین استفاده می‌کند. سپس
پاسخ مدل با نام/aliases آیتم‌های واقعی تطبیق داده می‌شود (حداکثر ۶ مورد) تا تصویر
پیشنهادها همیشه از دیتابیس بیاید و مدل نتواند آیتم خیالی بسازد.
